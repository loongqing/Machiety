# 玩法指南

你扮演「超越存在」：无法直接操控任何国民，只能通过神谕、灵感、灾难等间接手段影响世界——且所有干预都不可撤销。本页介绍界面操作、全部指令与六大文明系统的运作机制。

## 界面布局

Textual 四区布局：

- **顶部状态栏**：纪元日期、时代、人口、国家精神、生效政策
- **中央地图**：ASCII 地形渲染（含图例条），迷雾、资源、定居点、灾难与单位计数叠加显示
- **右侧面板**：信息面板（详情/指令回执）+ 事件日志（带图标的编年流水）
- **底部命令栏**：输入指令，支持历史回溯（↑/↓）与 Tab 补全

## 键盘与鼠标操作

| 按键 | 作用 |
| --- | --- |
| 方向键 | 移动地图光标 |
| `Enter` | 查看光标处地块/角色/定居点详情 |
| `w` | 追踪光标处角色（侧栏跟随显示详情）；再按取消 |
| `m` | 切换视图模式 |
| `z` | 缩放（单格 / 双格宽度渲染；双格模式叠加资源符号） |
| 鼠标点击 | 光标移动到点击地块 |
| `Space` | 暂停 / 继续模拟 |
| `Ctrl+Q` | 自动存档并退出 |

## 神谕指令全表

在底部命令栏输入（引号参数支持中英文引号包裹的空格文本）：

### 世界干预

| 指令 | 说明 |
| --- | --- |
| `miracle "神谕内容"` | 向全国广播一条神谕：写入所有存活角色的记忆，提升自我实现需求；代表人物会各自解读并口口相传（反应链），可能被国民「曲解」 |
| `disaster <类型> <地点>` | 降下灾难：`flood` 洪水 / `plague` 瘟疫 / `locust` 蝗灾 / `drought` 干旱；地点为定居点名或 `x,y` 坐标 |
| `inspire idea "概念"` | 向文明植入技术灵感种子，引导顿悟方向 |
| `inspire idea <领域> "概念"` | 领域定向灵感，领域支持中英文别名：粮食(food/农业/食物)、战争(war/军事/战斗)、精神(spirit/信仰/文化)、经济(economy/贸易/商业)、建造(build/建筑/工程) |
| `inspire <角色名> "记忆"` | 直接向特定角色植入一条核心记忆 |
| `gift <角色名> <物品>` | 凭空赐予物品（food/iron/luxury/任意词），增加库存、财富与影响力 |
| `decree "政策内容"` | 强行颁布国家政策，绕过议会；会引发派系不满与动荡累积（含「宣战」可讨伐外邦城邦） |
| `fund <定居点> [区域类型]` | 注入神力加速区域建设，或为无在建区域的定居点立项 |
| `launch wonder "名称"` | 发起奇观工程（同时只能建一项） |
| `honor <角色名>` | 授予国家荣誉，提升荣誉与影响力，助其涌现为伟人 |
| `avatar <角色名>` | 指定一位先知，之后的神谕将借其口传播 |

### 神民互动

| 指令 | 说明 |
| --- | --- |
| `prayers` | 查看等待回应的祈愿。国民每日可能向天祈愿，用对应的干预指令回应（如祈愿要粮就 `gift`），祈愿者获恩宠；7 日不回应会消散 |
| `talk <角色名> "话语"` | 与一位国民直接对话，他会以自己的性格与记忆作答，并记住这次神谕般的交谈 |

所有干预指令落地后都会激起**反应链**：先知、在场者与高影响力者率先作出个性化解读，随后在人群中逐小时传播发酵，直至议论平息。

| --- | --- |

| `status` | 国家概况：人口、定居点、存粮、财富、技术、时代、国家精神、探索度、LLM 后端 |
| `map` | 地图图例说明 |
| `epoch` / `policy` / `spirit` / `wonders` / `tech` | 查看时代 / 生效政策 / 国家精神 / 奇观 / 技术列表 |
| `history [条数]` | 翻阅编年史（默认最近 20 条） |

### 系统控制

| 指令 | 说明 |
| --- | --- |
| `skip [天数]` | 快进时间（默认 1 天） |
| `save [名称]` | 存档（缺省覆盖当前存档槽位） |
| `load [名称]` | 读档（缺省 `autosave`），会整体替换当前世界 |

## 六大文明系统机制

### 科技：灵感 → 顿悟 → 传播

无预设科技树。灵感池按五个类别（粮食、战争、精神、经济、建造）累积——来自研究行为、交易、饥饿、玩家 `inspire` 等；达到阈值触发**顿悟**，由 LLM 生成新技术的名称与效果，并从候选职业中选出发明者。已发明技术按识字率与道路网络（定居点联通近似）每日传播，并为相关活动提供加成。

### 政策：提案 → 投票 → 生效

派系按职业构成划分，每日可能由 LLM 生成提案；议会按支持度与成员影响力加权投票，通过后写入四槽位之一（军事、经济、外交、文化），每槽仅一项生效。玩家 `decree` 可强行颁布但累积**动荡值**，过高触发叛乱事件。国家精神由主导派系与生效政策合成。

### 城市：聚居 → 建城 → 区域

足够多居民聚居在无城之地时自发建立定居点。居民共同的主导需求映射为区域类型：市场、学宫、圣地、工业区、港口、剧院广场；区域由居民劳动逐步建成（技术提供加成），`fund` 可注入神力加速。城市每小时推进在建进度，每日尝试建城与提议新区域。

### 伟人：涌现 → 馈赠 → 遗产

影响力与荣誉之和达到阈值的角色，每日有机会涌现为**伟人**，由 LLM 生成伟大称号与馈赠。伟人死后留下文化遗产，发布历史事件。`honor` 指令可加速这一过程。

### 奇观：立项 → 建设 → 完成/烂尾

`launch wonder` 立项的跨代巨型工程，同一时间仅能建造一项。每日进度受人口与技术数量影响；连续无进展超过限制将**烂尾**。完成时由 LLM 生成效果与叙事文本，提供全局加成（如粮食、研究）。

### 时代：综合指数更迭

时代分数由科技数量与传播、政策槽位填充、定居点数量、文化事件、已完成奇观数合成；达到阈值即进入下一时代，发布时代事件（LLM 生成叙事文本）。

## 其他涌现机制

- **灾难**：自然与玩家降下的灾难在每日正午结算，影响地块资源、定居点存粮与建筑进度，持续数日后清理；灾难也可能催生相关技术灵感（如干旱催生灌溉）。
- **外邦城邦**：世界边缘存在外邦城邦与 NPC 市民；`decree "向外邦宣战"` 后军人行军讨伐，LLM 裁决胜负，胜者兼并城邦。
- **冲突**：同格多人且资源稀缺时可能爆发争夺（宜人性高者回避），由 LLM 裁决胜者与战利品。
- **昼夜节律**：黄昏进行夜间反思（记忆压缩、情绪与新目标）；8 点与 19 点为进食时间。

## 策略建议

| 阶段 | 目标 | 建议 |
| --- | --- | --- |
| 开局 | 建立首个定居点，稳住粮食 | 观察聚居趋势，必要时 `fund` 市场/工业区 |
| 成长 | 推动顿悟与政策成型 | `inspire idea` 定向引导；谨慎 `decree` 避免动荡 |
| 成熟 | 奇观与时代突破 | 保持人口与技术增长；`honor` 培育伟人 |
| 终局 | 完成奇观、进入现代 | 平衡资源与建设；用 `skip` 观察长期涌现 |
